# Iron Panthers Programming Training Hub
This is a platform that features the curriculum for the 2026-2027 school year, used to train new programmers! To access our slides directly, check out the Google Drive: https://drive.google.com/drive/folders/1At4QY1ueJhzWoPPdfRdKfebHgXqsX4Je?usp=sharing

Students can access:
* A dashboard with progress updates and announcements
* Training units with topic exercises, quizzes, and projects
* A sandbox, accessible alone or alongside slides
* Comments and feedback

Training Leads can access:
* A roster of students with student progress
* Student submissions
* Announcement and unit drafting
